# Talo Pay MCP

Remote [Model Context Protocol](https://modelcontextprotocol.io) server for [Talo Pay](https://talopay.com) — automatic bank-transfer payments for ecommerce in Argentina.

## Connect

| | |
|---|---|
| **MCP product page** | https://talo.com.ar/mcps/talo |
| **MCP endpoint** | https://talo.com.ar/mcp |
| **Website** | https://talopay.com |
| **Auth** | OAuth (remote HTTP) |

This repository documents the official remote MCP. The server itself is hosted by Talo (not open-sourced here).

## What it does

Talo Pay confirms bank transfer payments for online stores (Tiendanube, Shopify, WooCommerce, VTEX, Magento, and more). Each order gets a unique CVU/alias; Talo detects the payment and confirms the order.
